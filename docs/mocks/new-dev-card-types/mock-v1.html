New dev card types — mock v1

Four new dev kinds (Merchant, Trailblazer, Diplomat, Merit) in the existing dock/dev-bar language, plus the half-point score display and the lobby toggle. Everything below reuses the app's real panel colours, chip shapes, minicards and trade-grid patterns — nothing new is invented.

New kinds carry a violet tint (same hue as the existing “Buy dev” button) so they read as deck additions. Dashed border = bought this turn, unchanged rule. Icons: ⚖️ Merchant, 🧭 Trailblazer, 🕊️ Diplomat, 🎖️ Merit.

2 · Merchant — one 1:1 trade, up to 3

⚖️ Merchant

Give — pick one resource
Get — 1:1, same amount
3 of 3 used

Reuses the existing trade-grid. Picking a give-resource locks the other four (one type only); tapping it again steps the count 1 → 2 → 3. Card is consumed on confirm, not on open.

3 · Merit — +0.5 VP and a free resource

🎖️ Merit — pick a free resource

From the bank
Score 7 → 7.5 · two Merits make a full point

Same flow as the existing Year-of-Plenty / Santa-bonus picker. Empty bank stacks are disabled; if every stack is dry the panel skips straight through with “bank is empty”.

4 · Diplomat — steal cancelled at resolution

Red 6 Blue 5.5
robber placed on Red's hex
🕊️ Red played a Diplomat — the steal was blocked. Shield used up.

Placement is never blocked — the robber lands wherever it was aimed, then the steal fizzles and the shield is consumed. Nothing hints at the shield beforehand, so bots can't leak it. The holder sees their own Diplomat tinted in the dev bar; opponents see nothing until it fires.

Decisions this mock is asking you to confirm

  • Icons — ⚖️ Merchant, 🧭 Trailblazer, 🕊️ Diplomat, 🎖️ Merit. Emoji, matching the existing five.
  • Violet tint on new kinds — helps during the first few games, or visual noise once you know the deck?
  • Half-points everywhere — frame 4 shows opponents' chips reading “5.5” too. A played Merit is public, so this leaks nothing; a held one is still hidden. Confirm you want opponent halves shown, not just your own.
  • Merchant as one locked resource — up to 3 of a single type out, same count of a single type in. Not a free-form 3-for-3 mixed basket.
  • Diplomat visibility — holder sees their shield tinted; nobody else sees anything until it fires.
